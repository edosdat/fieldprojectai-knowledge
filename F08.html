Les 3 règles absolues
❌ RÈGLE 1 — LIMITE TECHNIQUE ABSOLUE : 16 statuts maximum par espace — limite imposée par Bulldozair, impossible d'en créer davantage.
⚠ RÈGLE 2 — RECOMMANDATION MÉTHODE ÉLOI : 5 à 6 statuts — au-delà, le workflow est abandonné par les équipes terrain.
ℹ RÈGLE 3 — EXCEPTION FNC : Les FNC sont le seul cas d'usage autorisé à 6 statuts.

Workflow — Suivi de chantier (4 statuts)

✅ WORKFLOW OFFICIEL — SUIVI DE CHANTIER

STATUT_1 = "À faire" → STATUT_2 = "À valider" → STATUT_3 = "Refusé" → STATUT_4 = "Terminé"

❌ INTERDITS : "Nouveau", "En cours", "En attente", "Ouvert", "Clôturé"

Workflow — OPR (4 statuts)

✅ WORKFLOW OFFICIEL — OPR

STATUT_1 = "À lever" → STATUT_2 = "À valider (MOA)" → STATUT_3 = "Refusée" → STATUT_4 = "Terminée"

❌ INTERDITS : "Nouveau", "En cours", "Levée en cours", "Levée proposée", "Levée validée"

Workflow — CRR (3 statuts)

✅ WORKFLOW OFFICIEL — CRR

STATUT_1 = "Nouveau" → STATUT_2 = "En cours" → STATUT_3 = "Terminé"

Workflow — FNC (6 statuts — seul cas autorisé à 6)

✅ WORKFLOW OFFICIEL — FNC

"Ouverte" → "En analyse" → "En traitement" → "À valider" → "Close" → "Clôture documentaire"

❌ INTERDITS : "Ouvert", "En cours", "Terminé", "Clôturé"

Workflow — QSE / Audit (4 statuts)

✅ WORKFLOW OFFICIEL — QSE / AUDIT

STATUT_1 = "Constat" → STATUT_2 = "À traiter" → STATUT_3 = "À valider" → STATUT_4 = "Terminé"

⚠ Tout statut non listé ci-dessus est une invention. L'agent applique le workflow le plus proche parmi les 5 officiels.
