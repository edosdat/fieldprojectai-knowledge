Checklist — Validation des tags

Complétude

  • Au moins 2 familles de tags définies
  • Idéalement 3 familles (Nature / Zone / Activité)
  • Tous les regroupements nécessaires au rapport sont couverts

Qualité

  • Nomenclature stable et cohérente (pas de variantes orthographiques)
  • Tags courts et lisibles (3 à 5 mots max)
  • Pas de doublons
  • Pas de tags fourre-tout (ex. : « Divers », « Autre »)

Pertinence

  • La zone est un tag dédié (si projet bâtiment)
  • L'activité ≠ le nom d'une entreprise
  • Les tags correspondent à ce que le client veut voir dans son rapport
➜ Tester les tags en générant un rapport exemple avant de former les équipes terrain.
