Construire et utiliser un template projet

Un template permet de démarrer chaque nouveau projet avec une structure cohérente, sans reconfigurer de zéro.

Ce que le template DOIT contenir

  • Tags (toutes les familles avec leurs valeurs)
  • Statuts (workflow complet)
  • Groupe de partage par défaut
  • Paramètres essentiels de l'espace

Ce que le template NE DOIT PAS contenir

  • Plans — ils sont spécifiques à chaque projet
  • Formulaires — ils sont liés au compte, pas au projet
  • Tâches — un template ne contient pas de données

Templates à créer par cas d'usage

TemplateContenu clé
Template Suivi de chantierTags Nature/Zone/Activité + workflow 4 statuts
Template OPRTags Zone/Activité + workflow MOA/MOE
Template FNCTags Type/Zone/Activité/Criticité + workflow 6 statuts
Template CRRTags Section/Sous-section + workflow 3 statuts
Template QSETags Nature QSE/Zone/Gravité + workflow 4 statuts
➜ Valider le template sur un rapport exemple avant de le déployer sur de vrais projets.
