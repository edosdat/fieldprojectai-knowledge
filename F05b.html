Pourquoi les groupes sont essentiels

Dans Bulldozair, l'attribution et le partage se font soit sur une personne, soit sur un groupe. Les groupes permettent d'attribuer une tâche à "Entreprise GO" sans devoir sélectionner chaque ouvrier individuellement.

➜ Sans groupes bien configurés, les attributions sont individuelles → surcharge manuelle → erreurs → tâches invisibles.

Les deux types de groupes

Type de groupeObjectifExempleUtilisé pour
Groupe interneRéunir l'équipe MOE/OPCGroupe MOE Projet XPartage par défaut — toutes les tâches visibles par l'équipe
Groupe entrepriseRéunir les membres d'un lotGroupe GO / Groupe CFAAttribution par lot — les réserves ou FNC vont à tout le lot

Groupes recommandés par cas d'usage

Cas d'usageGroupes recommandés
Suivi de chantierGroupe MOE interne (partage défaut) + 1 groupe par entreprise si > 3 personnes
OPR1 groupe par lot technique (attribution des réserves par lot)
FNC1 groupe qualité/QSE + 1 groupe par lot
CRRGroupe MOE + Groupe MOA si actifs dans le CRR
QSE / AuditGroupe QSE interne + groupes entreprises concernées
⚠ Pas de groupe interne = pas de partage par défaut fiable = tâches invisibles dans les rapports.
➜ Créer le groupe interne MOE EN PREMIER, avant d'inviter les autres utilisateurs.
